# station-de-recharge-intelligente-pour-v-hicules-lectriques-connect-e-au-r-seau-de-la-SRM-FM
Le projet développé sous MATLAB/Simulink comporte un redresseur actif PFC, un bus continu de 800 V, un hacheur Buck et un BMS Stateflow. Une supervision électro-thermique, fondée sur la température interne de la batterie, complète le délestage réseau
